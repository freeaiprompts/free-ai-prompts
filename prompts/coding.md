## Build a Full Landing Page with One Prompt

Generate a responsive, accessible landing page with pricing, FAQ, signup form and dark mode — in one HTML file.

**Works with:** Codex, Claude Code, Cursor, GitHub Copilot, ChatGPT, Claude  
**Type:** Code

```text
Build a complete, responsive one-page landing page for [product/business name], which [what it does]. Use a single index.html file with Tailwind CSS from the CDN and a little vanilla JavaScript. Sections: sticky header with logo and CTA, hero with headline, subheadline and [primary colour] button, 3 feature cards with icons, how-it-works in 3 steps, testimonials, pricing with 3 plans, FAQ accordion, email signup form, footer. Make it accessible (alt texts, labels, good contrast), mobile-first, with smooth scroll and a dark mode toggle. Use realistic placeholder copy for my audience: [audience].
```

**Tips**

- Claude Code and Codex can create the file directly in your project.
- Ask "now split it into components for React" if you use a framework.
- Paste your real texts later to replace the placeholders.
